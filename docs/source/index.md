# MLIA Ethos-U

## Purpose

`mlia-ethos-u` extends MLIA with Ethos-U target knowledge and the backend
plugins needed for Vela and Corstone-based analysis flows, including supported
ExecuTorch AOT runs through Corstone.

## Start here: Arm Learning Path

**[Analyze machine learning models for Arm Ethos-U with Arm ML Inference Advisor](https://learn.arm.com/learning-paths/embedded-and-microcontrollers/analyze-ethos-u-models-with-mlia/)**

Follow this hands-on guide to discover target profiles and backends, check model
compatibility, and interpret Vela estimates and Corstone performance results.
